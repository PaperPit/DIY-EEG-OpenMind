# Плата

Четырёхслойная плата 100 × 50 мм, 1,6 мм, FR-4, ENIG желательно (шаг выводов ADS1299 0,5 мм).

| Файл | Зачем |
|---|---|
| `pcb/gerber-rezonit.zip` | Gerber и сверловка для [Резонита](https://www.rezonit.ru/), смещение сверловки исправлено. Внутри `README_ЗАКАЗ.txt` со структурой слоёв |
| `pcb/stencil-rezonit.zip` | Трафареты TOP и BOTTOM, 0,12 мм |
| `pcb/gerber-jlcpcb.zip` | Тот же Gerber для заказа за границей |
| `bom.csv` | Перечень элементов, номиналы сверены со схемой |
| `shopping-list.csv` | Что купить в Чип и Дипе, на AliExpress и Ozon, с ценами-ориентирами (разделитель `;`, кодировка UTF-8) |
| `upstream/` | Схема, разводка и инструкция автора Low-Cost-EEG |

ADS1299 покупайте у продавца с рейтингом 97%+ и отзывами с фото. До подтверждения получения проверьте ID = 0x3E самотестом.
