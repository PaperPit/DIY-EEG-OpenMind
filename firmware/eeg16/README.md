# Прошивка на 16 каналов (две платы)

Для второго этажа: две платы Low-Cost-EEG друг над другом, связь через J5. Пошагово: [docs/05-16-channels.html](../../docs/05-16-channels.html).

| Окружение PlatformIO | Куда заливать | Что делает |
|---|---|---|
| `board_a` | нижняя плата A | Свои каналы 1–8 + каналы 9–16 от B по UART, Bluetooth `ESP32_EEG_DATA` |
| `board_b` | верхняя плата B | Каналы 9–16, отправляет каждый отсчёт на A. Bluetooth выключен |

J5 крест-накрест: TX A → RX B, RX A ← TX B, GND — GND. 921600 бод.

По Bluetooth идут отсчёты по 55 байт: счётчик, 27 байт платы A (3 статуса + 8 × 3), 27 байт платы B. По 3 отсчёта, 165 байт в уведомлении. [Просмотр сигнала](../../docs/viewer.html) сам переключается на 16 каналов.

**Монитор порта A (115200):** `t` включает и выключает внутренний тестовый сигнал на всех 16 каналах, `s` печатает отчёт о связи с B. Кнопка SW3 на A выключает ток проверки контакта на обеих платах.

**SYNC_CLOCK.** По умолчанию `0`: у каждого ADS1299 свой генератор, A берёт самый свежий отсчёт B. `1` только после провода между выводами 37 обеих ADS1299 и CLKSEL платы B на землю (шаг 9 инструкции). Значение должно совпадать на обеих платах.

Прошивка проверена компилятором только на синтаксис (с заглушками Arduino), на двух живых платах ещё не запускалась.
