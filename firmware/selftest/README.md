# Самотест ADS1299

Проверяет собранную плату изнутри: подлинность чипа (ID 0x3E), чтение и запись регистров по SPI, DRDY 250 Гц, размах AVDD−AVSS (около 5 В), температуру, тестовый сигнал, внутренний шум и путь сигнала через каждый вход. Подробное описание каждой строки вывода и что делать при FAIL в [части 2 инструкции](../../docs/02-tests-3d.html), шаги 6–11.

## Как прошить

1. Установите VS Code и расширение PlatformIO.
2. Скачайте прошивку автора: https://github.com/XavierAsghar/Low-Cost-EEG (Code → Download ZIP).
3. Скопируйте папку `Software/Firmware_Platformio_Project`, например в `Firmware_SelfTest`.
4. В копии замените `src/main.cpp` на [src/main.cpp](src/main.cpp) из этой папки. Папку `lib/ADS1299` не трогайте.
5. Откройте `Firmware_SelfTest` в VS Code и дождитесь, пока PlatformIO всё настроит.
6. Подключите плату по USB. SW1 в положение USB. Электроды **не** подключены.
7. Если порт не появился или загрузка не начинается: держите SW3 (BOOT), нажмите и отпустите SW2 (RESET), отпустите SW3.
8. Нажмите Upload. После загрузки нажмите SW2 (RESET).
9. Откройте Serial Monitor, скорость 115200.

## Команды в мониторе порта

- `t` повторить все тесты
- `m` живой монитор: размах сигнала по каналам и биты обрыва электродов

Перед тестом «Input path» соедините все 16 штырьков каналов (1+…8+, 1−…8−) с контактом GND на J3A.

После проверки верните авторский `main.cpp` и задайте `BIAS_SENSP` под свои каналы (шаг 12 части 2).

Код проверен на синтаксис, но ещё не компилировался на настоящем PlatformIO. Если появится ошибка компиляции, откройте issue с её текстом.
