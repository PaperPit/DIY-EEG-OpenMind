# Рабочая прошивка ЭЭГ

Проект PlatformIO для записи. Основа — прошивка [Xavier Asghar, Low-Cost-EEG](https://github.com/XavierAsghar/Low-Cost-EEG), GPL v3. Библиотека ADS1299 лежит в `lib/ADS1299`. Сборка под ESP32-S3-WROOM-1-N16R8: 16 МБ flash, 8 МБ PSRAM.

Откройте эту папку в PlatformIO и нажмите Upload. Плата по Bluetooth называется `ESP32_EEG_DATA`. Смотреть сигнал на Mac, Linux и Windows: [страница просмотра](../../docs/viewer.html) в Chrome или Edge. Safari Bluetooth в браузере не умеет.

Прошивка шлёт по 4 отсчёта, 112 байт. Так пакет помещается в уведомление Bluetooth на macOS. Программа автора `EEG_BLE_Receiver.exe` ждёт 224 байта и эту прошивку не разберёт.

**Параметры:** 250 отсчётов/с, усиление 24, референс SRB1. `BIAS_SENSP = 0b00000011`: в bias входят каналы 1 и 2. Для шапки на все 8 каналов поставьте `0b11111111`. Если регистр ID не равен 0x3E, прошивка останавливается: менять нужно ADS1299.

## Первая проверка альфы

Электроды только от аккумулятора.

| Гнездо | Куда |
|---|---|
| К1, канал 1+ | O1, затылок слева |
| К2, канал 2+ | O2, затылок справа |
| REF | сосцевидный отросток (мочка) слева |
| BIAS | лоб |

После подключения нажмите SW3 (BOOT). Это выключает ток проверки контакта. Повторное нажатие включает его снова. Пока ток включён, альфу смотреть рано. В просмотре закройте глаза на 20–30 секунд: на спектре каналов 1 и 2 в полосе 8–12 Гц вырастет альфа. Откройте глаза: пик спадёт. Для первой записи нужны мокрые Ag/AgCl. Сухой пассивный контакт даёт помеху 50 Гц уровня альфы.

Полоса на странице 1–40 Гц, плюс режектор 50 Гц.
