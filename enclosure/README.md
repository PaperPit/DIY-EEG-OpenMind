# Корпус и панель электродов

Прозрачный корпус из оргстекла 3 мм, снаружи 137 × 73 × 44 мм. Все детали вырезаются из листа 300 × 200 мм. В торцевой стенке 10 гнёзд TouchProof EE-B05 (8 каналов, REF, BIAS), на противоположной тумблер питания и два окна USB-C: данные платы и зарядка через TP4056.

| Файл | Зачем |
|---|---|
| `case-acrylic-3mm-cut.dxf` | Раскрой для мастерской лазерной резки |
| `case-drawings-1to1.pdf` | Чертежи деталей с отверстиями, печатать в масштабе 100 % |
| `panel-drill-template-1to1.pdf` | Шаблон сверловки стенки с гнёздами, 100 % |
| `shopping-list-panel.csv` | Оргстекло, клей, гнёзда, тумблер, TP4056, разъёмы |

Пошаговая сборка: [docs/04-panel-enclosure-3d.html](../docs/04-panel-enclosure-3d.html).

Порядок гнёзд снаружи: верхний ряд BIAS, К7, К5, К3, К1; нижний К8, К6, К4, К2, REF. Он повторяет порядок штырьков J3, поэтому провода внутри не перекрещиваются.

Шаблон рассчитан на резьбу M6. Чертежа EE-B05 у продавца нет: перед сверловкой измерьте резьбу и гайку у одного гнезда.
